# 網站文案編輯指南

正式入口：`https://nansiengtaiwan.com/admin/`。登入服務需先由網站管理者依 [啟用指南](CONTENT_ADMIN_SETUP.md) 完成設定與部署。

## 登入

1. 輸入已獲授權的 Email 與建立後台帳號時設定的密碼。
2. 按「登入文案後台」。這個密碼不是 Gmail 密碼。
3. 不需要 GitHub 帳號或登入信。忘記密碼請聯絡網站管理者。

若看到「登入服務尚未啟用」，代表管理者尚未完成設定。可點「先看看文案編輯介面」試用，試填內容不會儲存。

## 管理哪些內容

- 搜尋與分享：22 頁的搜尋標題、摘要、社群分享標題與說明。分享文字留白時，沿用搜尋文案。
- 到達頁文案：6 個到達頁的 H1、小標、介紹與內容段落。價格指南的報價因素與詢價引導在「價格說明」修改。
- 常見問題：龍獅介紹頁 FAQ，可新增、修改及移除。
- 服務介紹：表演項目標題、標籤、介紹與圖片替代文字。
- 價格說明：報價因素與詢價引導文字。

搜尋文案與頁面 H1 是不同欄位，需要分別修改。其他頁面的所有正文尚未全面開放編輯。

## 編輯與發布

1. 左側選擇分類與頁面，可先輸入關鍵字搜尋。
2. 修改欄位，右側／下方即時顯示文案預覽。
3. 按「檢查並發布」，核對頁面名稱與文案，再按「確認發布」。
4. 顯示「文案已提交」後，等待網站建置完成，再按「查看網站」確認。

若顯示版本衝突，先把自己的文字複製保留，再重新載入最新版本。不要直接覆蓋另一位編輯者的修改。發布失敗時，文字會保留在目前畫面；關閉分頁後不會自動保留草稿。

## 編輯提醒

- 使用自然、清楚的文字描述服務，確認活動名稱與事實後再發布。
- 分享圖片使用既有 `/images/` 路徑或 HTTPS 圖片網址。新增／上傳圖片請聯絡網站管理者。
- SEO 一覽是目前建置內容的示意，不代表搜尋引擎一定採用相同標題或摘要。
- 後台密碼只給自己使用，不轉傳給其他人。

原有進階 CMS 位於 `/admin/technical.html`，由有 GitHub 權限的技術管理者使用；圖片操作請參考 [圖片指南](ADMIN_IMAGE_GUIDE.md)。
