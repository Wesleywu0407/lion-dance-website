# 網站內容編輯指南

後台網址：`https://nansiengtaiwan.com/admin/`

主要負責新增或更換照片的管理員，請直接閱讀 [`ADMIN_IMAGE_GUIDE.md`](ADMIN_IMAGE_GUIDE.md)。

![Sveltia CMS 登入畫面](editor-guide/admin-login.png)

## 第一次登入

1. 先確認你的 GitHub 帳號已被加入網站 repository。
2. 開啟後台網址，按 **Sign in with GitHub**。
3. GitHub 詢問授權時確認應用程式名稱為「南仙網站內容管理」。
4. 完成後會進入內容列表。

> OAuth 尚未完成時，技術管理者可暫時使用 **Sign in with Token** 測試；一般編輯者不要自行建立或保存 Token。

## 修改文字

1. 從左側選擇「基本資料」、「服務項目」、「價格指南」、「常見問題」、「演出相簿」或「到達頁文案」。
2. 點選要修改的項目。
3. 修改欄位；有「必填」提示的內容不可留白。
4. 先用預覽確認標題、段落與圖片替代文字。
5. 按 **Save / Publish**。後台會把內容提交到 GitHub。

## 上傳相簿照片

1. 開啟「演出相簿」，選擇一本相簿。
2. 在「相片」清單按新增。
3. 上傳大圖；縮圖欄位可沿用既有 720px 圖片。
4. 填寫圖片替代文字，例如「紅色醒獅在公司開幕舞台進行採青」。不要只寫「照片」或檔名。
5. 填寫圖片寬度與高度後發布。

## 發布後

1. GitHub 會保存修改，Netlify 會自動建置與部署網站。
2. 通常約兩分鐘完成；若仍看到舊內容，重新整理一次。
3. 若五分鐘後仍未更新，不要重複發布，請把後台畫面交給網站管理者。

## 編輯注意事項

- 不要修改「系統代碼」或服務項目的「錨點 ID」。
- 電話連結必須是 10 碼數字，例如 `0922140496`。
- 圖片替代文字必填，描述畫面中的演出、人物與場合。
- 兩位編輯者避免同時修改同一筆內容，以免產生版本衝突。
- OAuth Client Secret、GitHub Token 等機密不可貼入內容欄位或傳到群組。
