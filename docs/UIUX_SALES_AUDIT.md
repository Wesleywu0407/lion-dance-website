# UI/UX 與接案漏斗稽核

稽核日期：2026-07-25

目標：讓活動主辦人更快理解南仙、確認適合度並送出可跟進的演出需求。

## 結論

網站已有成熟的視覺語言、清楚的演出照片與良好的手機快速聯絡列，但目前較像「內容完整的形象官網」，還不是能管理詢價與提升成交率的接案系統。

最重要的方向是：

1. 首頁信任感由南仙自己的能力建立。
2. 案例負責證明能力，不替品牌定義身分。
3. 聯絡表單蒐集可直接報價的結構化資訊。
4. 每筆洽詢進入自有案件資料庫，可追蹤、分派、跟進與統計。

## 已確認的優點

- 桌機首頁首屏有強烈龍獅視覺，品牌名稱、服務區域與 LINE CTA 清楚。
- 390px 手機版沒有水平溢出，固定快速列能直接電話、LINE 或預約。
- 服務頁已說明七種演出，並提供情境型到達頁。
- 聯絡頁同時提供 LINE、電話、Email 與表單，降低單一聯絡管道的流失。
- Eleventy 建置與本機連結檢查已通過。

## 優先問題

### P0：沒有自有詢價案件後台

目前表單直接送往 FormSubmit 與 Email。這會造成：

- 無法集中查看所有案件。
- 無法標記新詢價、已聯絡、報價中、成交或未成交。
- 無法記錄跟進時間與內部備註。
- 無法知道詢價來自首頁、哪個服務頁、哪個案例或廣告。
- Email 漏信時沒有第二份可靠紀錄。

證據：`src/pages/contact.html` 的表單 `action` 指向 `formsubmit.co`。

### P1：首頁讓 101 成為信任主角

首頁原本把「台北 101 演出」放在四個品牌特色中的第二項。這會讓訪客把知名場域當成南仙可信度的主要來源，而不是先理解南仙的訓練、規劃與執行能力。

處理原則：

- 首頁改為「一站式演出規劃／依活動與場地安排節目」。
- 101 繼續保留在開幕開工或百貨春節案例頁，並用真實照片與情境說明呈現。
- 首頁的結構化資料代表圖改用南仙自己的通用品牌圖片。

### P1：表單不足以直接進行估價

頁面文字請訪客提供日期、地點與流程，但表單沒有獨立的日期、地點、預算與回覆方式欄位，重要資訊全塞進「需求說明」。

後果：

- 訪客容易漏填日期或地點。
- 團長需要來回追問。
- 後台無法篩選某日檔期、區域或活動類型。

### P1：沒有來源與轉換事件

現在無法回答：

- 哪一頁帶來最多 LINE 點擊？
- 哪個活動類型最常詢價？
- 哪個案例最容易帶來成交？
- 表單在哪一欄流失？

需新增 `sourcePage`、UTM、referrer 與 CTA / form 事件。

### P1：共用內容仍大量複製

Header、Footer 與大型 JSON-LD 內容仍出現在多個來源頁面。雖然已有 `_includes`，但尚未完全成為唯一來源。品牌資料或結構化資料改動時，容易只改到部分頁面。

### P2：服務頁資訊完整，但選擇成本仍高

七種演出都有說明，但訪客仍要自己判斷「我的場合該選哪一種」。後續應加入簡短的情境選擇器：

- 開幕／開工
- 企業／尾牙
- 廟會／祝壽
- 商場／節慶
- 校園／教學
- 追思／儀式

選擇後直接帶出適合節目與預填詢價表單。

### P2：案例偏相簿，較少成交資訊

照片能證明演出經驗，但缺少主辦人最在意的資訊：

- 活動類型與場地條件
- 南仙如何安排節目與動線
- 演出項目與大致規模
- 現場執行重點
- 相似活動如何洽詢

不需要虛構成效數字；用真實流程就能建立專業信任。

## 建議的首頁順序

1. 品牌首屏：南仙名稱、服務區域、主 CTA。
2. 南仙能力：成立年資、一站式規劃、全台出團、快速回覆。
3. 依活動情境選方案。
4. 三個代表案例：不同場域，不以單一知名品牌主導。
5. 表演項目。
6. 四步預約流程。
7. 常見疑問或報價準備資訊。
8. LINE、電話與表單 CTA。

## 核心成效指標

- 首頁至 LINE 點擊率。
- 首頁至表單開始率與送出率。
- 每月有效詢價數。
- 完整填寫日期與地點的比例。
- 首次回覆時間。
- 詢價至報價、報價至成交轉換率。
- 各來源頁與活動類型的成交數。

所有指標只使用必要的業務資料，並依隱私政策設定保留期限。
