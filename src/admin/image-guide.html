圖片操作指南

給負責新增、替換或整理網站演出照片的管理員。依照下面步驟操作，不需要接觸程式碼。

30 秒快速流程

  1. 在後台左側選擇 演出相簿。
  2. 開啟要修改的相簿。
  3. 在 相片 區塊新增、替換、排序或移除照片。
  4. 填寫替代文字、圖片寬度及高度。
  5. 按 Save / Publish 發布。
  6. 等待約 2 分鐘，重新整理網站確認。

新增相簿照片

  1. 按 演出相簿，選擇照片所屬相簿。
  2. 找到 相片 清單，按新增。
  3. 在 大圖 上傳原始照片。
  4. 縮圖可留白；系統會在發布時自動產生適合網站的 WebP 尺寸。
  5. 填寫替代文字、圖片寬度和圖片高度。
  6. 按 Save / Publish。
替代文字怎麼寫？

好：紅色醒獅在公司開幕舞台進行採青表演。

不好：照片1、活動照片、直接貼檔案名稱。

查詢圖片寬度與高度

  • macOS：Finder 選取照片，按 Command + I，查看「更多資訊 → 尺寸」。
  • Windows：在檔案按右鍵，選「內容 → 詳細資料」。
  • 手機：開啟照片資訊或詳細資料，查看解析度。

例如 3024 × 4032：3024 填入寬度，4032 填入高度。

替換、排序或移除照片

  • 替換：在原本相片項目的大圖欄位上傳新照片，並更新替代文字與尺寸。
  • 排序：拖曳相片項目，把最重要、最清楚的照片放在前面。
  • 移除：按相片項目旁的刪除；相簿內至少保留一張照片。

從相簿移除照片不一定會刪除媒體庫原檔。要永久刪除前，請先確認其他頁面沒有使用它。

更換服務項目圖片

  1. 按 服務項目 → 表演項目列表。
  2. 展開要修改的表演項目。
  3. 更換 720px 圖片及 1440px 圖片。
  4. 更新替代文字、原始寬度與原始高度。
  5. 不要修改 錨點 ID，然後發布。

服務項目需要小圖與大圖兩個檔案。若只有未壓縮原圖，請交給技術管理者產生 720px 與 1440px 版本。

圖片規格

  • 格式使用 JPG、PNG 或 WebP。
  • 長邊建議約 1920px，單張建議小於 10MB。
  • 不要上傳模糊圖片、聊天截圖、含個資或未取得使用權的照片。
  • 照片方向錯誤時，先旋轉並另存新檔，再重新上傳。

發布後沒有更新怎麼辦？

  1. 先等待 2–5 分鐘。
  2. 重新整理網站，或使用無痕視窗確認。
  3. 仍未更新時，截圖後台畫面，交給技術管理者查看 Netlify 部署紀錄。
  4. 不要連續重複發布。

發布前檢查

  • 照片放在正確相簿。
  • 方向正確、畫面清楚。
  • 替代文字有描述表演與場合。
  • 寬度與高度填寫正確。
  • 沒有修改系統代碼或錨點 ID。
  • 發布後已用桌機與手機確認。
